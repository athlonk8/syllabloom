# Code of Conduct

We want this project to be a constructive, respectful place for learners and contributors of all backgrounds.

Be kind, assume good faith, give useful technical feedback, and respect privacy. Harassment, discriminatory behavior, publishing another person's private information, or sharing protected course material without permission is not welcome.

For a concern, use a private GitHub security advisory after publication rather than escalating publicly. Maintainers may remove content or contributions that violate these expectations.
