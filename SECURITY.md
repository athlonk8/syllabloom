# Security Policy

Syllabloom is local-first, but it can process personal notes and optionally contact a user-configured AI endpoint. Please report security or privacy issues privately.

After the repository is published, use GitHub's private security advisory flow for the repository. Do not include secrets, private course material, or real student answers in a public issue.

Useful reports describe the affected version, a minimal reproduction, impact, and whether the issue involves local-file boundaries, secret exposure, unintended network requests, or authentication bypass.

The project will not accept features that bypass course authentication, paywalls, SSO, Canvas, Gradescope, or equivalent access controls.
